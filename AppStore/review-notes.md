2. PURPOSE AND AUDIENCE
Domin-Uno is a scorekeeper for Mexican Train, a traditional dominoes game played by families and friends. A game runs 13 rounds; after each round every player adds up the pips left in their hand, and the running totals decide the winner. Doing this on paper is slow and error-prone. Domin-Uno tracks which double started each round, keeps every player's running total, can count the pips in a photo of a player's leftover tiles, and saves matches so a game can be finished another day.

3. HOW TO USE THE MAIN FEATURES
No login, account, setup, or sample files are needed.
- Players: type a name in the first row; a new empty row appears for the next player (up to 10).
- Points: tap a player's (x) field and type the points left in their hand. + / − sets whether (x) is added to or taken from their score; the total updates as you type.
- Starting double: tap the tile in the green row for the double that opened the round; it stays highlighted.
- Finish a round: after entering everyone's points, tap the highlighted tile in the blue row (outlined in red). Each total moves into (n), (x) resets to 0, and the highlight moves to the next tile. Typing points never ends a round by itself. Touch and hold the last yellow tile in the blue row to undo it.
- Count pips with the camera: touch and hold a player's (x) field, photograph domino tiles laid face up, check the count (it can be adjusted), and tap Use. Any domino tiles will do; without dominoes the points can simply be typed.
- Save / Open / New: Save asks for a name once, then the match saves itself after every round. Open lists saved matches to resume. New starts a fresh match.
